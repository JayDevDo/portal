<h1># portal</h1>
<p>JayVanDo.com canvas portal with links to FPL, WSL, JSD, JSD-AI and SVG-DARTBOARD.</p>
<p>Dials inherit the color of JayVanDo.com or another dial on collision, then return toward their own color only when they lose momentum by bouncing off a screen edge. After three edge bounces they are fully back to their own color.</p>
